## שלב 1: הקמת Docker (חלק ראשון, אתה)

```bash
# רשת
docker network create drupal-net

# בסיס נתונים: סיסמה my-secret-pw, פורט 5432, גרסה אחרונה
docker run -d --name drupal-db --network drupal-net \
  -e POSTGRES_USER=root \
  -e POSTGRES_PASSWORD=my-secret-pw \
  -e POSTGRES_DB=drupal \
  -p 5432:5432 \
  -v drupal-db-data:/var/lib/postgresql \
  postgres:latest

# Drupal על פורט 8080
docker run -d --name drupal-app --network drupal-net \
  -p 8080:80 \
  -v drupal-sites:/var/www/html/sites \
  drupal:latest

# בדיקה (חלק שני, סעיף 1)
docker ps
```

את הפקודות האלה הופכים ל-**`setup.sh`**, מוסיפים הודעות `echo` למשתמש, ועושים commit.

> #!/bin/bash

>

>
> echo "Backing up the Drupal sites folder..."
> docker exec drupal-app tar -C /var/www/html -czf - sites > sites_backup.tar.gz

> ```
>

> ```bash
> #!/bin/bash
> set -e
> echo "Starting restore process..."
>
> echo "Restoring the PostgreSQL database..."
> docker exec -i drupal-db psql -U root -d drupal < drupal_db_backup.sql
>
> echo "Restoring the Drupal sites folder..."
> docker exec -i drupal-app tar -C /var/www/html -xzf - < sites_backup.tar.gz
>
> echo "Restarting Drupal..."
> docker restart drupal-app
>
> echo "Restore completed successfully! Open http://localhost:8080"
> ```
